# Support

Thanks for using FED-LINk — here is how to get help fast, from the fastest
option to the slowest.

## :zap: Fastest: the FAQ

Before opening anything, check `FAQ.md`. It covers the classics: "Why is my
redirect not 301?", "Why do I get a 404 on a slug I just added?", "Why
doesn't `.htaccess` work in the folder I uploaded?", and "How do I change the
redirect target after the link is live?" — all with fixes.

## :book: Documentation

The full handbook lives in `docs/` (and on the project's GitHub Pages site):

- `docs/installation.md` — Python, venv, Docker, or prebuilt apps
- `docs/usage.md` — CLI, GUI, and Kivy front ends
- `docs/configuration.md` — links files, slug rules, template placeholders
- `docs/deployment.md` — IONOS DNS, InfinityFree `htdocs`, verification with `curl`
- `BUILD.md` / `DEPLOYMENT.md` — building the project and shipping it
- `README.md` — the quick start

## :beetle: Found a bug?

Open an issue using the bug report template
(`.github/ISSUE_TEMPLATE/bug_report.md`). Include the CLI command you ran,
your links file (redact anything sensitive), and whether the problem happens
on every run or only sometimes. Attach the generated file if it looked wrong.

## :bulb: Want a feature?

Open a feature request (`feature_request.md`) and describe the workflow you
are trying to improve, not just the mechanism. Feature requests that come
with a use case get priority.

## :speech_balloon: Questions and discussion

Use GitHub Discussions — the `discussion/` folder in this repository holds
the starter categories and the welcome text (see
`.github/DISCUSSION_WELCOME_README.md`). Questions go under **Q&A**, ideas
under **Ideas**, and showing off your short-link setup under **Show and
tell**.

## :lock: Security issues

Never use a public issue for security. Follow `SECURITY.md` and email
security@fedpromptly.com instead.

## :money_with_wings: Commercial support

There is no paid tier and no support contract — FED-LINk is a small,
dependency-free tool. If you need help integrating it into a bigger system,
open a Discussion thread with the details; the maintainer answers what time
allows.

If FED-LINk saved you a subscription fee, consider supporting it at
